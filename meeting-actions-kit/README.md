# Example: meeting notes → next steps

A repeatable writing task with no scripts or external services. All data is fictional.

## Try it

1. Start `pi` in `meeting-actions-kit/` after reading the skill.
2. Ask: **"Turn these meeting notes into follow-ups."**
3. If necessary, load it with `/skill:meeting-actions`.

## Check the result

- Three actions: Alex's captions, Morgan's permissions check, Alex's sample label.
- Two explicit decisions.
- Printing is an open need, not an assigned action.
- The audio tour and newspaper ideas are not commitments.
- Only Morgan's committed action is missing an owner or deadline (its deadline is unspecified).
- "Friday" and "our next meeting" stay as written.
- No files are changed.
