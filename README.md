# Heartland AI Symposium – Pi Workshop

This repository contains the materials for the **Heartland AI Symposium Pi workshop**. The workshop wiki holds the full documentation, guides, and downloadable handouts for working with **pi**, the AI coding assistant with read, bash, edit, write tools.

## 📚 Documentation Wiki

All up-to-date documentation lives in the GitHub Wiki:

* [Wiki Home](https://github.com/sawyerb-ksu/heartland-ai-symposium-pi/wiki)
  * Overview, quick links, workshop materials and current handouts/slides.

* [Installing Pi.dev](https://github.com/sawyerb-ksu/heartland-ai-symposium-pi/wiki/Installing-Pi.dev)
  * PowerShell installation instructions, Node.js requirements, and how to add providers.

> The wiki is the canonical source for instructions. Please refer to the wiki for the latest versions of guides and resources.

## 📁 Repository Contents

* `resources/` – Current handouts and presentation slides referenced from the wiki Home page:
  * `Workshop_Resources.pdf`
  * `Pi.dev AI Coding Assistant Cheat Sheet.pdf`
  * `SKILL_DESIGNER.md`
* `PresentationSlides.pptx` – Slide deck covering installation and documentation overview.
* `scan-renamer-kit/` – Example skill: rename scanned files with an approval step.
* `webpage-briefing-kit/` – Example skill: turn a webpage URL into a source-linked report, with an offline practice page.
* `spreadsheet-check-kit/` – Example skill: flag CSV data-entry errors without changing the source.

* `tools/` – Helper scripts.

The two additional kits each include a ready-to-use `.agents/skills/` folder,
fictional sample input, and a README with a demo prompt, expected results and
ideas for customization. Start Pi inside the kit you want to try.

Handouts are also linked directly from the wiki Home page for easy download.

## Getting Started

1. Read the installation guide: [Installing Pi.dev](https://github.com/sawyerb-ksu/heartland-ai-symposium-pi/wiki/Installing-Pi.dev)
2. Visit the [Wiki Home](https://github.com/sawyerb-ksu/heartland-ai-symposium-pi/wiki) for resources, cheat sheets, and workshop materials.
3. Download the latest PDFs from `resources/` or via the links on the wiki Home page.
